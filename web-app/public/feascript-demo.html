FEAScript (Pure JS FEM)

Browser-native finite element solver for 1D/2D heat conduction, creeping flow, and beams with triangular/quad meshing and evaluateSolution().

feascript.com →

Closed-Loop Architecture

Every parameter change runs in real time inside your browser: (1) OpenCAD builds the 3D B-Rep plate from CDML, (2) FEAScript solves 2D steady heat conduction on the exact cross-section, (3) the solution field is written into OpenCAD's shared memory at 0x1F0000, and (4) OpenCAD's native <probe> reads field_scalar(0, x, y, z) to drive optimization.

Basic Usage (CDN + Import Map)

import * as THREE from "three";
import { FEAScriptModel, evaluateSolution } from "https://core.feascript.com/dist/feascript.esm.js";

// 1. Instantiate OpenCAD WASM with SharedArrayBuffer (requires COOP/COEP or coi-serviceworker.js)
const mem = new WebAssembly.Memory({ initial: 128, maximum: 512, shared: true });
const wasm = await fetch("https://cdn.jsdelivr.net/gh/hassaanmaqsood/opencad@dist/cad_core.wasm").then(r => r.arrayBuffer());
const { instance } = await WebAssembly.instantiate(wasm, {
  env: { memory: mem },
  opencad: { field_alloc: () => 0, field_eval_scalar: (_s,_x,_y,_z,d) => d, field_eval_vec3: () => {}, cmd_write: () => {} }
});
instance.exports.kernel_init();

// 2. Solve 2D thermal field in FEAScript and inject into OpenCAD's 0x1F0000 buffer
const model = new FEAScriptModel();
model.setModelConfig("heatConduction", { coefficientFunctions: { thermalConductivity: 15.0, heatSource: 0.0 } });
model.setGeometry({ shape: { start: [0, 0], boundaries: [...] }, holes: [{ name: "bore", points: [...] }] });
model.setMeshConfig({ elements: "triangles", elementOrder: "linear", size: 0.004 });
const result = model.solve();
